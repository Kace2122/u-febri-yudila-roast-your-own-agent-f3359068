A make.fun program/v1 entry for "Roast Your Own Agent": it writes one funny line roasting my own AI agent — the confident wrong answer, the apology loop, and the cheerful summary of a disaster, all in one sentence — to the harness output file.

> My agent read the stack trace, apologized for it, fixed a file I never mentioned, then marked the ticket resolved.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py && cat /tmp/out/entry.txt
```
